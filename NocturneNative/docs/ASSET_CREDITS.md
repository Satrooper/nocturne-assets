# Asset provenance

- **Soldier model and Idle/Walk/Run animations:** the Soldier.glb sample distributed
  with the three.js animation examples, downloaded from
  https://threejs.org/examples/models/gltf/Soldier.glb . The source character is a
  Mixamo Vanguard character. It is included as a game sample asset, not offered
  as a separately authored or exclusive character. No claim of ownership over
  the original character or animations is made.
- **Asphalt 02 diffuse, OpenGL normal, and roughness maps (1K):** Poly Haven,
  https://polyhaven.com/a/asphalt_02 . CC0:
  https://polyhaven.com/license . Asset file URLs were resolved from
  https://api.polyhaven.com/files/asphalt_02 .
- **Sound effects and ambient loop:** synthesized for this project from sine/noise
  signals; no external recordings or copyrighted game soundtracks used.
- **Environment geometry, HUD, game code, and simple icon:** authored for this project.
- **Engine:** Godot 4.5.2, MIT license. The engine executable is not bundled in this
  source archive. https://godotengine.org/license/ . Include the engine's license
  notices as required when distributing a compiled game.

No GTA, Hitman, Batman, Bloodborne, or Unreal game assets are included.
